## 二、审计发现（问题清单）

### 2.1 🔴 P0 — 语言切换整体失效（引擎层竞态）

**现象**：登录页点击 English 按钮，界面**纹丝不动**（真实 E2E 取证：I18N-UI-001 连续失败，快照仍为全中文）。

**根因链**（[i18n-context.tsx](file:///Users/yanyu/YYC-Cube/YYC3-Administration/src/app/components/i18n-context.tsx)）：

```
React setLocale('en')          ← 状态立变,触发重渲染
  ↓ 重渲染帧
AuthPage 调 t(key)
  → engine.t(key)              ← engine.setLocale 在 useEffect 中,
  → 返回【中文值】(非 key)        此时 engine.locale 仍是 zh-CN
  → str !== key,fallback 不触发 ← 界面显示中文,且无人再触发重渲染
```

- `engine.setLocale` 位于 `useEffect`（提交后才执行），**渲染帧内引擎永远滞后一拍**
- 引擎返回旧语言值而非 key 本身，使 `str === key` 的 fallback 判定永远失效
- 旧逻辑依赖引擎返回 key 来触发扁平字典兜底——该前提在竞态窗口内不成立
