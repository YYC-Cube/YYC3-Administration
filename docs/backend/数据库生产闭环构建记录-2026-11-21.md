## 二、关键操作留痕（可复现）

```bash
# 1. 账号与授权（postgres@45）
CREATE ROLE yyc3_admin_app LOGIN PASSWORD '<api-keys.env 取值>';
GRANT CONNECT ON DATABASE yyc3_admin TO yyc3_admin_app;
\c yyc3_admin
GRANT USAGE, CREATE ON SCHEMA public TO yyc3_admin_app;
GRANT ALL ON ALL TABLES IN SCHEMA public TO yyc3_admin_app;
GRANT CREATE ON DATABASE yyc3_admin TO yyc3_admin_app;      -- drizzle 建 journal schema
GRANT USAGE, CREATE ON SCHEMA drizzle TO yyc3_admin_app;    -- journal 读写
ALTER TABLE drizzle.__drizzle_migrations OWNER TO yyc3_admin_app;

# 2. hba（pg_hba.conf 尾部 + reload）
host yyc3_admin yyc3_admin_app 192.168.3.0/24 scram-sha-256
host yyc3_admin yyc3_admin_app 100.64.0.0/10 scram-sha-256

# 3. 迁移上生产（项目根）
DATABASE_URL="postgres://yyc3_admin_app:<pw>@192.168.3.45:5433/yyc3_admin" pnpm db:migrate
```

## 三、踩坑留痕（GLM-5.3 审核关注点）

| 坑                                                 | 修复                                                                              |
| -------------------------------------------------- | --------------------------------------------------------------------------------- |
| `permission denied for database`                   | drizzle migrator 需**库级 CREATE**（建 journal schema）——GRANT CREATE ON DATABASE |
| `permission denied for schema drizzle`             | journal schema 建成后仍需 schema 级 USAGE+CREATE                                  |
| `permission denied for table __drizzle_migrations` | journal 表曾以 postgres 建成 → **ALTER ... OWNER TO yyc3_admin_app**              |
| 生产表 5/6（缺 user_documents）                    | 45 库落后 0001 迁移 → 补跑后 6/6                                                  |

## 四、放行三准核验

3. ☑ 告警在线（实例级监控 */5）
